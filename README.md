# ☕ Café Demo | GFK Studio Web Boutique Tech

Proyecto web frontend desarrollado con mejores prácticas, diseñado para demostrar un flujo de desarrollo limpio, moderno y de alto rendimiento. Ideal para cafeterías, restaurantes o negocios locales con estilo boutique.

## 🚀 Tecnologías y Herramientas
* **HTML5** (Estructura semántica moderna)
* **CSS3** (Variables, Flexbox, Glassmorphism y diseño responsivo)
* **JavaScript (Vanilla)** (Efectos de scroll interactivos y control de navegación)
* **Font Awesome** (Iconografía moderna)
* **Google Fonts** (Tipografía *Poppins*)
